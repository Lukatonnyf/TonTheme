# Description
**TonTheme** is a modern dark theme for Visual Studio Code, developed for programmers who spend long hours coding and need a clear, consistent, and comfortable visual experience.

---

## 🌈 Color Palette

- **Editor**: Dark background (#1B1913) with discreet cursor and smooth selection highlighting.
- **Code Tokens**: Distinct cores for functions, variables, strings, numbers, and comments, ensuring contrast and readability.
- **Interface**: Activity bars, tabs, sidebar, and terminal with harmonious, non-distracting colors.
- **Markdown**: Enhanced support for courses, links, emphasis, and lists with custom cores.

---

## ⚡ Features

- Elegant dark theme, easy on the eyes.
- Full syntax highlighting for multiple languages.
- Custom Markdown: highlighted titles, links, lists, and punctuation.
- Semantic Highlighting enabled.
- Focus on developer experience: menus, bars, and widgets fully integrated into the palette.

---

## Installing TonTheme in VS Code

You can install the theme locally using the provided `.vsix` file. Follow the steps below:

### 1. Prerequisites
- VS Code installed
- `code` command available in the terminal

- If not, open VS Code and press `Ctrl+Shift+P` (or `Cmd+Shift+P` on Mac)

- Type `Shell Command: Install 'code' command in PATH` and press Enter

### 2. Installing the extension
Download the `.vsix` file from the repository and run the following in the terminal:

```bash
code --install-extension tontheme-0.0.1.vsix
```
